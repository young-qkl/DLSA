# Third-Party Code

This implementation is built on the public RMSIN/LAVT codebase and includes
adapted utility code from MMCV. It also uses PyTorch, torchvision, timm,
Hugging Face BERT utilities, and the REFER dataset API.

Please follow the licenses and citation requirements of the corresponding
upstream projects and datasets. This repository follows the GNU GPL v3 license
used by the upstream LAVT implementation.
